STATUS CODE PARA FIXAR

GET sucesso = 200 OK
POST criado = 201 Created
PUT sucesso = 204 NoContent
DELETE sucesso = 204 NoContent
Não encontrado = 404 NotFound
Erro de dados = 400 BadRequest

Verbos HTTP

GET → Buscar informação.
POST → Criar informação.
PUT → Atualizar informação.
DELETE → Apagar informação.
